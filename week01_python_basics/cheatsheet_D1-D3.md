## 0. 三条元规则（想不起来的时候先看这里）

**① 带括号的是「动作」，不带括号的是「名字」。**
- 动作：`print(...)`、`len(...)`、`int(...)`、`.replace(...)`
- 名字：`title`、`amount`、`row`
- 推论：方法要挂在东西身上 —— `dirty.replace(...)` 对，光写 `replace(...)` 报 `NameError`。

**② 方法不改原变量，只交给你一个新结果。**
- `dirty.strip()` 之后 `dirty` 还是带空格的。想留住结果必须 `clean = dirty.strip()`，或写链式 `dirty.strip().replace(...)`。
- **例外**：`sort()` 直接改原列表，而且**返回 None** —— `x = mylist.sort()` 会得到 `None`，千万别这么写。

**③ 一行末尾有冒号 `:` → 下一行必须缩进 4 个空格。**
- 缩进决定「这行归谁管」：`if` / `for` / `while` / `def` 后面都适用。
- 报 `IndentationError` 先查空格，别查逻辑。

## 0.5 三种括号 + f-string（2026-09-26 补：这两处我栽过跟头）

**一句话口诀：动手用圆、取东西用方、造容器用大。**

| 括号 | 角色 | 例子 |
|------|------|------|
| `()` 圆 | **做动作**：函数 / 方法调用、运算分组 | `print("你好")`、`int("35")`、`len(rows)`、`title.strip()` |
| `[]` 方 | **取东西**：按下标 / 键 / 切片取出来 | `rows[0]`、`lines[-1]`、`nums[1:3]`、`row["发布年份"]` |
| `{}` 大 | **造容器**：字典、集合 | `{"状态": "进行中"}`、`{"教育部", "财政部"}` |

**三个必须记住的易错点（都是实跑过的）**

1. **动作后面只能是圆括号。**
   `print {int(3.5)}` → `SyntaxError: Missing parentheses in call to 'print'. Did you mean print(...)?`
   —— Python 自己把改法写在报错里了，见到 `SyntaxError` 先读那句英文提示。
2. **字典用 `{}` 造，用 `[]` 取。**
   造：`row = {"政策名称": "教育信息化2.0"}`；取：`row["政策名称"]`。
   写成 `row{"政策名称"}` → `SyntaxError: invalid syntax. Perhaps you forgot a comma?`
3. **f-string 里的 `{}` 是「占位开关」**，和字典的 `{}` 不是一回事——只在引号**内部**、且引号前有 `f` 时才生效。

**f-string 三行对照（实测输出）**

```python
name = "陈驰"
print("你好，name")     # 你好，name     ← 没 f 没 {}，全是普通文字
print(f"你好，name")    # 你好，name     ← 有 f 但没 {}，还是普通文字
print(f"你好，{name}")  # 你好，陈驰      ← {} 才是开关
```

> 我 D1 默写时写的 `print(f"最后6个字： sentence[-6:]")`，输出的是字面量
> `最后6个字： sentence[-6:]`——就因为 `sentence[-6:]` 没包进 `{}`。
> 正确写法 `print(f"最后6个字： {sentence[-6:]}")` → `最后6个字： 解到工程实现`。

## 1. D1 · 变量、字符串、数字

### 1.1 四种类型

| 写法 | 类型 | 说明 |
|------|------|------|
| `project_name = "教育部数智安防建设试点"` | `str` 字符串 | 文本，必须带引号 |
| `batch_amount = 1000000` | `int` 整数 | |
| `success_rate = 0.35` | `float` 浮点数 | 小数 |
| `is_approved = False` | `bool` 布尔 | 只有 `True` / `False`，**首字母大写** |

- 看类型用 `type(x)`。
- Python 区分大小写：`"p0"` ≠ `"P0"`，`false` 也不是 `False`。

### 1.2 字符串（以 `title = "关于推进教育数字化的若干意见"` 为例，共 14 字）

| 写法 | 会得到 | 提醒 |
|------|--------|------|
| `len(title)` | `14` | 一个汉字算一个 |
| `title[0]` | `关` | **下标从 0 开始** |
| `title[-1]` | `见` | 负数从末尾数 |
| `title[3:9]` | `进教育数字化` | 切片**含头不含尾**（取到下标 8） |
| `title.replace('教育','教育信息化')` | `关于推进教育信息化数字化的若干意见` | 换掉**所有**匹配项 |
| `title.startswith('关于')` | `True` | |
| `'  有空格  '.strip()` | `有空格` | 只去首尾，中间的不管 |

**切片口诀：要「最后 N 个」就写 `[-N:]`，冒号后面留空。**
以 `sentence = "从业务理解到工程实现"`（10 字）为例，实测：
- `sentence[-6:]` → `解到工程实现` ✅（想要的结果）
- `sentence[-7:-1]` → `理解到工程实` ❌（整体左移一格，还丢了最后的「现」）
- 原因：起点**包含**、终点**不包含**，这个规则不对称。别用负数终点去凑。

### 1.3 f-string（天天用）

```python
sentence = "从业务理解到工程实现"
print(f"最后6个字：{sentence[-6:]}")
```

```
f"{dept} 正在跟进 {project_name}，本批 {batch_amount:,} 元，成功率 {success_rate:.0%}"
```

| 花括号里的写法 | 作用 | 实测输出 |
|---------------|------|---------|
| `{x:,}` | 千分位 | `1,000,000` |
| `{x:.0%}` | 转百分比、不带小数 | `0.35` → `35%` |
| `{x!r}` | 原样显示（能看见引号和空格） | `' 有空格 '` |

> **头号坑（2026-09-26 实跑）**：`{}` 漏写 → 表达式被当成普通文字原样打印。
> `print(f"最后6个字： sentence[-6:]")` 输出 `最后6个字： sentence[-6:]`，
> 必须写成 `print(f"最后6个字： {sentence[-6:]}")` 才输出 `解到工程实现`。详见第 0.5 节。

### 1.4 数字运算

| 写法 | 结果 | 记法 |
|------|------|------|
| `7 / 2` | `3.5` | 真除法，结果**一定**是小数 |
| `7 // 2` | `3` | 整除 |
| `7 % 2` | `1` | 取余，判奇偶常用 |
| `2 ** 10` | `1024` | 幂 |
| `round(3.14159, 2)` | `3.14` | |
| `round(3850/100, 2)` | `38.5` | 不足两位不会补 0 |

> 你踩过的坑：`17 % 5` 写成了 `17 / 5`，得到 3.4。三个符号别混：`/` 除、`//` 整除、`%` 余。

### 1.5 类型转换（读文件/网页拿到的是文本，必须先转）

| 情况 | 写法 | 结果 |
|------|------|------|
| 纯整数文本 | `int("1200")` | `1200` |
| 带小数点的**文本** | `int(float("3.5"))` | `3`（先过 float 这道门） |
| 带千分位逗号 | `float("1,200".replace(",",""))` | `1200.0` |
| 两边有空格 | `int(" 12 ")` | `12`（Python 自动去空格，能成功） |
| 小数转整数 | `int(3.9)` | `3`（**直接截断，不是四舍五入**） |
| `input()` 拿到的 | 永远是 `str` | 要算就得 `int()` / `float()` |

> `int("3.5")` 和 `int("1,200")` 都会报错——这是你 D1 实跑出来的结论。

## 2. D2 · 四种容器

**一句话定位：**列表装一串 / 元组锁死 / 字典按名字取 / 集合去重。

| 容器 | 写法 | 能改吗 | 取值方式 | 用在哪 |
|------|------|--------|---------|--------|
| `list` 列表 | `["A003", "A011"]` | ✅ | 按位置 `[0]` | 一堆有序记录 |
| `tuple` 元组 | `("编号","事项","状态")` | ❌ | 按位置 `[0]` | 不该被改的固定项 |
| `dict` 字典 | `{"编号":"A005","状态":"进行中"}` | ✅ | 按名字 `["状态"]` | 一条记录的字段 |
| `set` 集合 | `{"教育信息化","数智安防"}` | ✅ | 无下标 | 去重、交集并集 |

### 2.1 列表常用动作

| 写法 | 效果 | 提醒 |
|------|------|------|
| `append(x)` | 加到**末尾** | 想加到最后就用它 |
| `insert(0, x)` | 插到最前 | 数字是「新元素要抢占的**座位号**」，不是「插到第几个之后」 |
| `insert(-1, x)` | ⚠️ 插到**倒数第二** | 实测：`["b","a","c"]` → `["b","a",x,"c"]`。要追加别用负数 |
| `remove(x)` | 按**值**删除 | 写值不写下标 |
| `sort()` | 直接改原列表 | **返回 None**，不能赋值接收 |
| `len(lst)` | 个数 | |
| `x in lst` | `True`/`False` | 判断在不在里头 |

### 2.2 字典

| 写法 | 效果 |
|------|------|
| `project["状态"]` | 取值；**键不存在会 KeyError 崩掉** |
| `project.get("负责人", "（未填写）")` | 取值；键不存在返回默认值，**不崩** |
| `project["状态"] = "已闭环"` | 改值 |
| `project["完成日期"] = "2026-09-14"` | 新增字段（原本没有就直接加上） |
| `project.keys()` / `.values()` | 所有键 / 所有值 |

### 2.3 集合

```
set(["智慧校园","职教云","智慧校园","教育大模型","职教云"])   # 3 个
# 保序去重要用：list(dict.fromkeys(tags))  → ['智慧校园','职教云','教育大模型']
team_a & team_b    # 交集（两边都有）
team_a | team_b    # 并集（合起来）
team_a - team_b    # 差集（只在 A 里）
```

### 2.4 ★ 列表套字典 = 真实数据的标准形态（最重要）

```python
ledger = [
    {"编号": "A003", "事项": "小奔体育商机", "状态": "进行中", "优先级": "P1"},
    {"编号": "A005", "事项": "租房合同归档", "状态": "已闭环", "优先级": "P2"},
    {"编号": "A011", "事项": "北湖第 2 批报账", "状态": "进行中", "优先级": "P0"},
]
```

| 写法 | 结果 |
|------|------|
| `ledger[0]["事项"]` | `小奔体育商机`（先取第 1 条→字典，再按键取值） |
| `len(ledger)` | `3` |
| `[row["编号"] for row in ledger if row["状态"] == "进行中"]` | `['A003', 'A011']` |

读嵌套的口诀：**从左到右一层层拆**。

## 3. D3 · 控制流

### 3.1 if / elif / else

```python
if priority == "P0":
    action = "今天必须处理"
elif priority == "P1":
    action = "本周内安排"
else:
    action = "进待办池"
```

- `==` 是「比较」，`=` 是「赋值」，别写混。
- 可以链式比较：`500000 < amount <= 2000000`
- 判断属于某一类：`'进行中' in ['进行中','待确认','待反馈']`

> 你 D3 练习【1】的坑：把答案**手打**进 `print(f"... → 大额")`，`if` 一次都没执行。判断必须由 `if` 做出来，不能由人做出来。

### 3.2 for 循环

| 写法 | 用途 |
|------|------|
| `for row in ledger:` | 逐个遍历（最常用） |
| `for i in range(len(ledger)):` | 只要序号 |
| `for i, row in enumerate(ledger, start=1):` | **序号 + 内容都要**（逗号拆包；`start=1` 让序号从 1 开始） |
| `for k, v in ledger[0].items():` | 遍历一个字典的键和值 |

> 你问过的两个点：
> - `for i, row` 的逗号 = 「这一轮要拿**两个**东西」，左边名字的**个数**必须和右边对上，少写一个名字就会把整对装进一个变量 → `TypeError: tuple indices must be integers, not str`。
> - 那个 `.` 只是 `f"{i}. {row['编号']}"` 里的一个**普通字符**，换成 `、`、`@` 都行。

### 3.3 ★「先建 X，再用 Y」型（你在这上面栽过两次）

筛选、计数、收集结果，套路完全一样：**循环之前先建好空容器 / 计数器**。

```python
doing = []                      # ① 循环前建好
for row in ledger:              # ② 遍历
    if row["状态"] == "进行中":   # ③ 判断
        doing.append(row["编号"]) # ④ 符合条件的收进来
print(doing)                    # ⑤ 循环后再用
```

计数器版：`count = 0` → 循环里 `count += 1` → 循环后 `print(count)`。

> 你 D3 练习【5】的问题就是「只 print 了，没往列表里放」，转完就丢。

### 3.4 while / break / continue

| 关键字 | 行为 |
|--------|------|
| `while 条件:` | 条件为真就一直转，**必须有让条件变假的语句**（如 `i += 1`），否则死循环；卡住了按 `Ctrl+C` |
| `break` | 满足条件直接**跳出整个循环**（找到 P0 就不用再找了） |
| `continue` | **跳过这一条**，继续下一条 |

### 3.5 try / except

```python
good = []
for item in ["1200", "800", "未知", "3500", ""]:
    try:
        good.append(int(item))
    except ValueError:
        print(f"跳过脏数据：{item!r}")
print(good)          # [1200, 800, 3500]
```

- 实测：`"未知"` 和 `""` 都被拦下，`int("")` 抛的也是 `ValueError`，一条 `except` 足够。
- 不确定会抛什么错时兜底用 `except Exception as e:`，但别静默吞掉——接住之后要么处理、要么打印出来。

## 4. 最易混的 8 组对照

| # | 易混 | 区别 |
|---|------|------|
| 1 | `/` vs `//` vs `%` | 真除（必得小数）/ 整除 / 取余 |
| 2 | `s.strip()` vs `s = s.strip()` | 前者原变量不变 / 后者才留住结果 |
| 3 | `append(x)` vs `insert(-1, x)` | 追加到末尾 / 落到**倒数第二** |
| 4 | `d["键"]` vs `d.get("键", 默认)` | 键缺失时：报错崩掉 / 返回默认值 |
| 5 | `sort()` 的返回值 | 是 `None`，它改的是原列表；别写 `x = lst.sort()` |
| 6 | `break` vs `continue` | 跳出整个循环 / 只跳过这一条 |
| 7 | `print {...}` vs `print(...)` | 动作后面只能用圆括号；用大括号报 `Missing parentheses in call to 'print'` |
| 8 | f-string 漏 `{}` | 没包进 `{}` 的表达式是**普通文字**，不会被求值 |

## 5. 我踩过的坑（`notes/W1.md` 报错记录本摘录）

| 报错 / 现象 | 真正原因 | 修法 |
|-------------|---------|------|
| `"policy_title" is not defined`（一次 6 个） | 用了变量但没先赋值 | 用到它的行之前先赋值 |
| `NameError: name 'replace' is not defined` | 方法没挂"主语" | `dirty.replace('2017','2018')` |
| `strip()` 之后还有空格 | 方法不改变原变量 | `clean = dirty.strip()` 或链式 |
| 余数算出 3.4 | `%` 写成 `/` | `17 % 5` → 2 |
| `[-7:-1]` 切错 | 起点包含、终点不包含 | 一律写 `[-N:]` |
| `insert(-1,...)` 落到倒数第二 | 数字是座位号不是"第几个之后" | 追加用 `append` |
| `TypeError: tuple indices must be integers, not str` | `enumerate` 的逗号拆包被去掉 | 写回 `for i, row in enumerate(...)` |
| 「大额/常规/小额」打印对了但没判断 | 答案手打进 print，if 没参与 | 遍历 + `if` 比大小 |
| 转换成功但数字没留住 | 只 print 没 append | 循环前建空列表 |
| `int("3.5")`、`int("1,200")` 报错 | 小数文本要过 float；逗号不认 | `int(float("3.5"))` / 先 `.replace(",","")` |
