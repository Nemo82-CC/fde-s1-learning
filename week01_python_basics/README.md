## 二、每天怎么用这些文件（三步）

每个 `.py` 文件都是「可运行 + 带讲解 + 带练习」的三合一，用法固定：

1. **读**：从上往下读，注释里会写「应该输出什么」。
2. **跑**：按 `Ctrl+S` 保存 → 点 VS Code 右上角 ▶ 运行 → 看下方终端输出。
3. **练**：翻到文件下半部分的「动手练习」，自己写；写完再往下滑看参考答案。

> 参考答案在每个文件的最底部，**别提前滑**，先自己写错一遍比看答案学得快。

## 四、每天结束后把代码推到 GitHub（4 步，1 分钟）

1. VS Code 左侧点「源代码管理」图标（分叉那个）。
2. 在「更改」里点文件旁的 `+`，把要提交的文件暂存。
3. 上面的输入框写一句提交信息，例如：`feat: W1D1 Python 基础语法练习`。
4. 点 ✓ 提交，再点「同步更改」（↗）推送到 GitHub。

## 五、顺延原则（重要，别硬扛）

工作日必然会有忙不过来的晚上。**规则只有一条：不攒账。**

- 某天没做 → 第二天接着做前天那份文件，日程整体后移一天，**不跳过、不一次补两天的量**。
- 一周只完成了 5 天 → 那就 9 天完成 W1，完全正常。
- 唯一不能妥协的是：**当天打开的练习必须写完再 commit**，不要「读一遍就提交」。
