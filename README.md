## 长周期不掉线（2026-09-24 定，防止 7–8 个月的计划烂尾）

这么长的周期，最大风险不是慢，是**断太久之后不再捡起来**。三条机制，成本都很低：

1. **每月 checkpoint（最后一个周末，30 分钟）**：① 更新各模块的块进度；② 往 `notes/` 补一句
   「这个月我能独立做出来的事」；③ 看下个月有没有出差周，提前把练习 commit 掉。
2. **断更红线：连续 2 周 0 块 → 转维持模式**。不强推新内容，只做维持包（读速查卡 / 默写函数 / 口述报错本）
   + 复习已学，等节奏回来再推进。**允许慢，不允许断。**
3. **每月至少 1 次 commit 留痕**，哪怕只是更新笔记——仓库里连续的痕迹本身就是坚持的可视化。
