## 6. 报错记录本

| 报错信息 | 原因 | 怎么修好的 |
|---------|------|-----------|
| `"policy_title" is not defined`（Pylance 警告，一次报了 6 个） | 用了变量但没先给它赋值。Python 从上往下执行，`名字 = 值` 才是"创建这个名字"的动作 | 在用到它的那行之前，先补三行赋值 |
| `NameError: name 'replace' is not defined` | 方法必须挂在某个字符串身上，只写 `replace(...)` 就没有"主语" | 改成 `dirty.replace('2017', '2018')` |
| 结果不对：`改年份:` 后面仍带首尾空格 | `strip()` **不改变原变量**，只返回处理后的新值；下一行还是从带空格的 `dirty` 出发 | 用中间变量 `clean = dirty.strip()` 再对 `clean` 做替换；或写成链式 `dirty.strip().replace(...)` |
| 结果不对：`余数：3.4` | 把取余 `%` 写成了真除法 `/` | 改成 `17 % 5` → 2。记牢：`/` 真除法、`//` 整除、`%` 取余 |
| 结果不对：`[-7:-1]` 切出「理解到工程实」 | 切片的起点是**包含**的、终点是**不包含**的，两头各偏一格 | 改成 `[-6:]`。口诀：要「最后 N 个」，永远写 `[-N:]`，冒号后面留空 |
| `insert(-1, "A001 立项")` 插到了**倒数第二**，不是最后 | `insert` 的第一个数字是「新元素要抢占的座位号」，不是「插到第几个之后」。`-1` 是 A012 现在占的座位，A001 抢了它，A012 被挤到最后 | 想追加到最后就直接用 `append(x)`，不要用负数去算位置 |
| `TypeError: tuple indices must be integers, not str` | `enumerate` 那行我把 `for i, row` 改成了 `for row`（去掉逗号），此时 `row` 装的是整对 `(序号, 记录)`，再去 `row['编号']` 就是用字符串键去索引元组 | 拆包写回来：`for i, row in enumerate(ledger, start=1)`；或硬取 `row[1]['编号']`（不推荐） |
| 练习【1】屏幕上确实出现「大额 / 常规 / 小额」，但程序一次判断都没做 | 把答案**手打**进了 `print(f"... → 大额")`，`if` 完全没参与；另外 `nemo = "p0"` 判的是优先级字符串，不是题目给的金额 | 改成遍历 `test_amounts`，用 `if ... >= 1000000` 比大小。附带：Python 区分大小写，`"p0"` ≠ `"P0"` |
| 练习【5】转换都成功了，但数字没留住 | 只 `print` 了，没往列表里放，转完就丢 | 循环前 `good = []`、成功时 `good.append(...)`、循环后 `print(good)` —— 和【3】题是同一个「先建 X，再用 Y」套路 |
| `int("3.5")` 报错；`int("1,200")` 也报错 | 带小数点的**文本**必须先过 `float()` 这道门；千分位逗号两个函数都不认 | `int(float("3.5"))`；`float("1,200".replace(",", ""))`。注意 `int(3.9)` = 3，是直接截断不是四舍五入 |
